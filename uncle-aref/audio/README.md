# ملفات الصوت المطلوبة — «المشوار الأول»

لا يوجد أي تسجيل صوتي في المشروع حتى الآن، لذلك المعاينة الحالية فيها ترجمة ومؤثرات فقط، **بدون صوت**.

## المواصفات
- **الصوت:** رجل مصري في أواخر الخمسينات، حنون وتلقائي، يتكلم على مهله بابتسامة مسموعة، مع وقفات قصيرة. لا يقلّد ممثلًا بعينه.
- **الصيغة:** WAV بتردد 48 kHz أو 44.1 kHz، ‏16 أو 24 bit، مونو.
- **التسجيل:** مكان هادئ بدون صدى أو موسيقى، مع ترك ربع ثانية من الصمت قبل الكلام وبعده.
- **ملف لكل جملة:** باسم المعرّف بالضبط، ويوضع في `audio/vo/`.
- **المدد المكتوبة تقديرية فقط.** الريندر يأخذ طول كل تسجيل كما هو، بدون تسريع أو إبطاء، ويعيد ضبط توقيت اللقطات والترجمة وحركة الشفايف حسب التسجيل.

## بعد إضافة الملفات
```bash
cd uncle-aref/tools && python3 render.py
```
- لو كل الملفات موجودة، يخرج الفيديو النهائي `out/ep01_first_ride.mp4`، من غير علامة «معاينة».
- لو فيه ملف ناقص، يفضل الفيديو معاينة باسم `out/ep01_first_ride_PREVIEW.mp4`.
