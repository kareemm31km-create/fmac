# عم عارف — الحلقة ١ «المشوار الأول»

ريل رأسي 9:16 (1080×1920، ‏25 إطار/ث)، كرتون ثنائي الأبعاد مبني بالكامل من شيتات الشخصية المعتمدة في `refs/`.
كل الأدوات محلية ومجانية: Python ومعاها Pillow وNumPy وSciPy وfontTools، وFFmpeg.

## التشغيل
```bash
cd tools
python3 extract.py       # قص الطبقات من الشيتات → assets/cutouts
python3 face.py          # نقاط الشنب والعين لكل وش → assets/cutouts/anchors.json
python3 backgrounds.py   # الشارع وداخل التاكسي من مكان الراكب ولقطة التابلوه → assets/bg
python3 sfx.py           # مؤثرات مولّدة: باب، كاسيت، كلب الزينة، شارع هادي → audio/sfx
python3 render.py        # ستوري بورد + MP4 → out/
python3 render.py --storyboard-only     # ستوري بورد بس
python3 render.py --frames 4.5,14       # صور ثابتة من ثواني معيّنة → build/
```

## الهيكل
- `episode/ep01_first_ride.json`: اللقطات، والحوار مقسّم لجمل، والتعبير المستخدم لكل جملة، وتوقيت المؤثرات.
- `audio/README.md`: قائمة ملفات الصوت المطلوبة (`audio/vo/L01.wav` … `L21.wav`).
- `build/timeline.json`: التوقيت الفعلي بعد آخر ريندر.
- الخط: Cairo (رخصة OFL، الملف في `assets/fonts/`). الحروف العربية واللاتينية مدموجين في ملف واحد بـ fontTools.

## قواعد ثابتة في الكود
- الملامح واللبس وحجم الراس مأخوذين من الرسم المعتمد نفسه، من غير إعادة رسم ولا عكس للصورة. عشان كده اتجاه العينين ثابت: دايمًا ناحية الراكب، أي ناحية الكاميرا.
- الشفايف بتتحرك بأشكال الفم من الشيت ٢، والرمش برسمة الجفن بلون البشرة زي «Eye blink studies».
- التاكسي أسود في أبيض، من غير أي لون أصفر. لقطات الزجاج الأمامي من برّه مافيهاش كاسيت ولا عدادات داخلية. الكاسيت بيظهر بس في لقطة داخلية.
- التاكسي واقف طول الحلقة، ومافيش أي حركة قيادة.
- مدة كل جملة = طول تسجيلها بالظبط، من غير تسريع. لو التسجيل ناقص، الفيديو يطلع بعلامة «معاينة».
